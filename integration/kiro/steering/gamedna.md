# GameDNA

This project uses GameDNA. For work that builds or changes a game, activate the `gamedna-director` skill and follow it: it reads `.gamedna/profile.json`, keeps shared facts in Game Contracts and delegates game systems to the `gamedna-*` specialist agents. Small single-system changes do not need the Director. Before writing a game system, check the GameDNA Kit for an existing module.
